## Окружение

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

ПР1 и ПР3 используют TensorFlow в отдельном окружении, команды в их README.
Отчёты собираются из `report.md` скриптом `tools/gost_report.js` (Node.js, пакет docx, LibreOffice для номеров страниц в содержании).
