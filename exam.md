Билет из двух теоретических вопросов. Каждый ответ рассчитан на устный пересказ за две-три минуты:
определение, как это работает, формула, где это было в моих работах.

Ссылки на работы: КР курсовая (авиапассажиры), ЛР1 полносвязная сеть (Fashion-MNIST),

ЛР5 датасет из API Hacker News, ПР1 Colab и MNIST, ПР2 LSTM на температуре, ПР3 автокодировщики,
ПР4 датасет из API GitHub, ПР5 тональность на русском.

## 1. Обзор задач машинного обучения

Машинное обучение это построение алгоритма по данным: вместо того чтобы программист прописал правила,
модель сама находит зависимость между входом и ответом по примерам.

Основные типы задач:
- **Классификация**: предсказать класс объекта из конечного набора. КР (доволен ли пассажир),
  ЛР2 (тональность отзыва), ЛР4 (что на фото).
- **Регрессия**: предсказать число. ПР2: температура на завтра, MAE 1,735 °C.
- **Кластеризация**: разбить объекты на группы без готовых меток. КР: K-Means на авиапассажирах.
- **Понижение размерности**: сжать признаки с минимальной потерей информации. КР: PCA,
  две компоненты объясняют 29,4 % дисперсии.
- **Обнаружение аномалий**: найти объекты, не похожие на остальные. ПР3: автокодировщики.
- **Ранжирование и рекомендации**, **обучение с подкреплением** (агент учится действовать
  в среде по награде).

По наличию разметки задачи делятся на обучение с учителем (есть правильные ответы), без учителя
(ответов нет) и смешанное. Общая схема решения любой задачи одинаковая: собрать и подготовить данные,
выбрать модель и функцию потерь, обучить, оценить на отложенных данных, которые модель не видела.
Последний пункт главный: качество на обучающей выборке ничего не говорит о работе на новых данных.

## 2. Классификация алгоритмов машинного обучения

Алгоритмы группируют по нескольким признакам.

**По типу обучения:** с учителем (логистическая регрессия, деревья, SVM), без учителя
(K-Means, иерархическая кластеризация, PCA), смешанные и обучение с подкреплением.

**По виду модели:**
- линейные: линейная и логистическая регрессия, линейный SVM;
- метрические: k ближайших соседей, решают по расстоянию до известных объектов;
- логические: деревья решений, набор правил «если, то»;
- ансамбли: случайный лес (бэггинг), градиентный бустинг;
- нейронные сети: полносвязные, свёрточные, рекуррентные;
- вероятностные: наивный байесовский классификатор.

**Параметрические и непараметрические.** У параметрической модели фиксированное число параметров,
которое не растёт с данными (логистическая регрессия: по весу на признак). Непараметрическая хранит
данные или усложняется вместе с ними (kNN запоминает всю выборку, дерево растёт).

**Порождающие и разделяющие.** Порождающие моделируют, как устроены данные каждого класса, P(x | y).
Разделяющие сразу ищут границу между классами, P(y | x).

**Ленивые и энергичные.** kNN ничего не делает при обучении и считает всё при предсказании,
остальные наоборот.

На практике разница видна в ЛР3: пять алгоритмов разных групп на одних данных дали от 0,732
(линейная модель) до 0,838 (ансамбль деревьев).

## 3. Линейные модели регрессии

Линейная регрессия предсказывает число как взвешенную сумму признаков:

  ŷ = w₀ + w₁x₁ + … + wₙxₙ = wᵀx

Веса подбираются так, чтобы минимизировать среднеквадратичную ошибку:

  MSE = (1/N) Σ (yᵢ − wᵀxᵢ)²

**Способы найти веса.** Аналитически: w = (XᵀX)⁻¹Xᵀy, нормальное уравнение. Работает, пока признаков
немного, обращение матрицы дорогое. Численно: градиентный спуск, w ← w − η·∇MSE, шаг за шагом
в сторону уменьшения ошибки.

**Регуляризация** защищает от переобучения и от неустойчивости при коррелированных признаках:
- Ridge (L2): к ошибке добавляется λΣwᵢ², веса сжимаются к нулю;
- Lasso (L1): добавляется λΣ|wᵢ|, часть весов обнуляется, получается отбор признаков.

**Оценка качества:** MAE (средняя абсолютная ошибка, в единицах ответа), RMSE (сильнее штрафует
большие промахи), R² (доля объяснённой дисперсии, 1 идеал, 0 уровень среднего).

**Предположения:** зависимость линейная, ошибки независимы, признаки не дублируют друг друга.

В ПР2 линейная регрессия по 30 предыдущим дням предсказывала температуру: MAE 1,745 °C, R² 0,670.
Сеть LSTM дала почти то же самое (1,735 °C), потому что суточная температура почти линейно зависит
от последних дней. Это хороший пример, когда простая модель не хуже сложной.

## 4. Базисные функции

Линейная модель умеет только прямые линии. Чтобы описать нелинейную зависимость и при этом оставить
модель линейной по весам, признаки пропускают через базисные функции:

  ŷ = w₀ + Σ wⱼ·φⱼ(x)

Модель остаётся линейной относительно весов w, значит её обучают теми же способами, что и обычную
линейную регрессию, но относительно исходного x она уже нелинейная.

**Виды базисных функций:**
- полиномиальные: φⱼ(x) = xʲ, получается полиномиальная регрессия;
- гауссовы (радиальные): φⱼ(x) = exp(−‖x − μⱼ‖² / 2s²), «колокол» с центром μⱼ;
- сигмоидные: φⱼ(x) = σ((x − μⱼ) / s);
- тригонометрические: синусы и косинусы, для периодических процессов;
- для текста: слова и пары слов.

**Риск:** чем больше базисных функций, тем гибче модель и тем легче переобучиться. Высокая степень
полинома проходит через все точки обучения и дико колеблется между ними. Помогает регуляризация.

**Связь с моими работами.** В ЛР2 TF-IDF с парами слов это по сути базисные функции над текстом:
каждое слово и каждая пара становятся отдельным признаком, а модель поверх остаётся линейной
логистической регрессией. Метод опорных векторов с ядром RBF в ЛР3 работает с гауссовыми базисными
функциями неявно, через ядро, не вычисляя сами признаки.

## 5. Целевая функция логистической регрессии

Логистическая регрессия предсказывает вероятность класса 1:

  p = σ(wᵀx) = 1 / (1 + e^(−wᵀx))

Сигмоида переводит любое число в интервал от 0 до 1.

**Целевая функция** это логарифмическая функция потерь (log-loss, кросс-энтропия):

  L(w) = −(1/N) Σ [yᵢ·log pᵢ + (1 − yᵢ)·log(1 − pᵢ)]

Откуда она берётся: это минус логарифм правдоподобия. Вероятность увидеть всю выборку при данных весах
равна произведению pᵢ для объектов класса 1 и (1 − pᵢ) для класса 0. Логарифм превращает произведение
в сумму, а максимизация правдоподобия становится минимизацией L.

**Смысл:** если объект класса 1 получил p = 0,99, штраф −log 0,99 ≈ 0,01. Если p = 0,01, штраф
−log 0,01 ≈ 4,6. Уверенная ошибка наказывается очень сильно.

**Почему не MSE:** с сигмоидой MSE становится невыпуклой функцией с локальными минимумами,
а log-loss выпуклая, у неё один минимум, и градиентный спуск его находит.

**Градиент** получается простым: ∇L = (1/N) Σ (pᵢ − yᵢ)·xᵢ. Решения в явном виде нет, веса ищут
итерационно. С регуляризацией к L добавляется λ‖w‖².

В ЛР2 логистическая регрессия на TF-IDF дала accuracy 0,8736. В КР без масштабирования признаков
оптимизатор не сошёлся за 1000 итераций и выдал ConvergenceWarning, после стандартизации сошёлся.

## 6. Структура нейрона

Искусственный нейрон это упрощённая модель нервной клетки. Он получает несколько входов,
складывает их с весами и пропускает через функцию активации:

  z = w₁x₁ + w₂x₂ + … + wₙxₙ + b
  a = f(z)

**Составные части:**
- **входы** x₁…xₙ: признаки объекта или выходы нейронов предыдущего слоя;
- **веса** w₁…wₙ: насколько важен каждый вход, их и настраивают при обучении;
- **смещение** b: сдвигает порог срабатывания, позволяет нейрону сработать и при нулевых входах;
- **сумматор**: считает взвешенную сумму z;
- **функция активации** f: добавляет нелинейность.

**Функции активации:**
- пороговая: 1, если z > 0, иначе 0, была в первом перцептроне;
- сигмоида σ(z) = 1/(1 + e^(−z)): выход от 0 до 1, но при больших |z| градиент почти нулевой;
- гиперболический тангенс tanh: выход от −1 до 1, использовался в автокодировщиках ПР3;
- ReLU = max(0, z): простая, быстро считается, не затухает для положительных z,
  стандарт для скрытых слоёв, был во всех моих сетях в ЛР1 и ЛР4;
- softmax на выходном слое: превращает выходы в вероятности классов, сумма равна 1.

**Зачем нелинейность.** Без функции активации любая многослойная сеть сворачивается в одну линейную
модель: композиция линейных преобразований линейна. Только нелинейность позволяет сети описывать
сложные зависимости.

Один нейрон с сигмоидой это ровно логистическая регрессия.

## 7. Структура нейронной сети

Нейронная сеть это нейроны, собранные в слои:
- **входной слой** принимает признаки, вычислений не делает;
- **скрытые слои** преобразуют данные, каждый следующий описывает всё более сложные сочетания признаков;
- **выходной слой** выдаёт ответ: одно число для регрессии, вероятности классов для классификации.

В **полносвязном** (плотном) слое каждый нейрон соединён со всеми нейронами предыдущего слоя.
Слой задаётся матрицей весов W и вектором смещений b: a = f(Wx + b).

**Прямой проход:** вход последовательно проходит через слои, на выходе получается предсказание.
Затем считается функция потерь, и при обучении веса правятся обратным распространением ошибки.

**Число параметров** считается просто. В ЛР1 сеть 784 → 128 → 10:
первый слой 784·128 + 128 = 100 480, второй 128·10 + 10 = 1 290, итого 101 770 параметров.
Сеть с тремя слоями 256, 128, 64 имела 242 762 параметра, а выиграла всего 0,25 процентного пункта.

**Глубина и ширина.** Больше слоёв позволяет строить иерархию признаков, больше нейронов в слое
увеличивает ёмкость. Но чем больше параметров, тем выше риск переобучения.

**Приёмы против переобучения:** дропаут (в ЛР1 0,2, в ЛР4 0,3), ранняя остановка по валидации,
регуляризация весов, аугментация данных.

**Гиперпараметры:** число слоёв и нейронов, функции активации, скорость обучения, размер батча,
число эпох. Их подбирают по валидационной выборке, не по тестовой.

## 8. Перцептрон

Перцептрон предложил Фрэнк Розенблатт в 1958 году. Это первая обучаемая модель нейрона
и первый алгоритм обучения нейронной сети.

**Устройство:** один нейрон с пороговой функцией активации:

  ŷ = 1, если wᵀx + b > 0, иначе 0

Геометрически перцептрон проводит гиперплоскость и относит объекты по разные стороны к разным классам.

**Правило обучения:** объекты подаются по одному, при ошибке веса сдвигаются к правильному ответу:

  w ← w + η·(y − ŷ)·x

Если ответ верный, (y − ŷ) = 0, веса не меняются. Если объект класса 1 назван 0, веса сдвигаются
в сторону x.

**Теорема сходимости:** если классы линейно разделимы, перцептрон за конечное число шагов найдёт
разделяющую гиперплоскость.

**Ограничение:** перцептрон решает только линейно разделимые задачи. Минский и Пейперт в 1969 году
показали, что он не может выучить даже XOR: точки (0,0) и (1,1) одного класса, (0,1) и (1,0) другого,
одной прямой их не разделить. Это надолго остудило интерес к нейросетям.

**Выход:** многослойный перцептрон. Скрытый слой с нелинейной активацией преобразует пространство так,
что задача становится разделимой. Для XOR хватает двух скрытых нейронов. Обучать такие сети научились
с появлением метода обратного распространения ошибки.

Все полносвязные сети в моих работах (ЛР1, ПР1) это многослойные перцептроны, только с активацией ReLU
вместо пороговой, потому что пороговая функция не дифференцируема.

## 9. Виды нейронных сетей

**Полносвязные (многослойный перцептрон).** Каждый нейрон связан со всеми нейронами предыдущего слоя.
Подходят для табличных данных. На изображениях теряют соседство пикселей: в ЛР1 на Fashion-MNIST
потолок около 0,89.

**Свёрточные (CNN).** Слой применяет маленький фильтр (3 на 3) ко всем участкам изображения,
выделяя локальные признаки: края, текстуры, части объектов. Пулинг уменьшает карту признаков.
Веса фильтра общие для всего изображения, поэтому параметров мало. ЛР4: своя сеть из четырёх
свёрточных блоков и ResNet18.

**Рекуррентные (RNN, LSTM, GRU).** Обрабатывают последовательность по элементам и хранят состояние.
LSTM с вентилями не забывает начало длинной последовательности. ЛР2 (тексты), ПР2 (временной ряд).

**Автокодировщики.** Учатся восстанавливать вход через узкое горлышко, получая сжатое представление.
Применяются для сжатия, удаления шума, обнаружения аномалий. ПР3.

**Трансформеры.** Вместо рекуррентности механизм внимания: каждый элемент последовательности смотрит
на все остальные сразу. Основа современных языковых моделей (BERT, GPT).

**Генеративно-состязательные сети (GAN).** Генератор создаёт объекты, дискриминатор отличает их
от настоящих, обе сети учатся друг против друга.

**Сети радиально-базисных функций (RBF).** Скрытый слой из гауссовых нейронов, отвечающих на близость
к центру.

**Остаточные сети (ResNet).** Слои с обходными связями x + F(x), позволяют обучать очень глубокие сети.
В ЛР4 дообученная ResNet18 дала 0,664 против 0,501 у своей сети.

## 10. Функциональное назначение нейронных сетей

Нейросети решают почти все типы задач машинного обучения. По назначению:

- **Классификация**: отнести объект к классу. Распознавание изображений (ЛР1, ЛР4), тональность
  текста (ЛР2), диагностика по снимкам.
- **Регрессия и прогнозирование**: предсказать число или продолжение ряда. Прогноз температуры (ПР2),
  спроса, цен.
- **Кластеризация и сжатие**: сети Кохонена группируют объекты, автокодировщики строят сжатое
  представление данных.
- **Обнаружение аномалий**: автокодировщик как одноклассовый классификатор (ПР3). Большая ошибка
  восстановления значит объект не похож на обучающие.
- **Генерация**: создание изображений, текстов, музыки (GAN, диффузионные модели, языковые модели).
- **Обработка последовательностей**: перевод, распознавание речи, суммаризация текстов.
- **Извлечение признаков**: сеть, обученная на большой задаче, даёт полезные представления для другой.
  В ЛР4 свёрточные слои ResNet, обученные на ImageNet, распознали скорпионов после обучения одного
  последнего слоя. В ПР5 векторы слов Navec, обученные на художественных текстах, сработали для
  тональности рецензий.
- **Управление**: обучение с подкреплением, игры, робототехника.

Нейросети выигрывают, когда данных много и признаки сложные (изображения, звук, текст).
На небольших табличных данных ансамбли деревьев часто лучше: в КР градиентный бустинг дал 0,965,
а в ЛР2 обученная с нуля LSTM проиграла логистической регрессии 13 процентных пунктов.

## 11. Обратное распространение ошибки

Метод обратного распространения ошибки (backpropagation) считает градиент функции потерь по всем
весам сети. По этому градиенту веса обновляются градиентным спуском.

**Идея:** потеря зависит от весов через цепочку слоёв, поэтому производная считается по правилу
дифференцирования сложной функции, от выхода к входу.

**Алгоритм:**
1. Прямой проход: для каждого слоя z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾, a⁽ˡ⁾ = f(z⁽ˡ⁾). Запоминаются все z и a.
2. Ошибка выходного слоя: δ⁽ᴸ⁾ = ∂L/∂a⁽ᴸ⁾ ⊙ f′(z⁽ᴸ⁾).
3. Обратный проход: δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾)ᵀ δ⁽ˡ⁺¹⁾ ⊙ f′(z⁽ˡ⁾). Ошибка передаётся назад через те же веса.
4. Градиенты: ∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾(a⁽ˡ⁻¹⁾)ᵀ, ∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾.
5. Обновление: w ← w − η·∂L/∂w, где η скорость обучения.

Весь градиент считается за один обратный проход, поэтому метод эффективный: стоимость того же порядка,
что и прямой проход.

**Проблемы:**
- затухание градиента: производная сигмоиды не больше 0,25, и при перемножении по многим слоям
  градиент исчезает. Решения: ReLU, батч-нормализация, остаточные связи, в рекуррентных сетях LSTM;
- взрыв градиента: обрезка градиента;
- локальные минимумы и плато: стохастический градиентный спуск, Adam.

На практике градиенты считаются автоматически: в PyTorch `loss.backward()`, дальше
`optimizer.step()`. Именно эти две строки стоят в цикле обучения в ЛР1, ЛР2, ЛР4 и ПР2.
Оптимизатор Adam подстраивает шаг для каждого веса отдельно, поэтому я использовал его везде.

## 12. Структура деревьев решений

Дерево решений это модель в виде набора вопросов, организованных иерархически.

**Элементы:**
- **корень**: первый вопрос, через него проходят все объекты;
- **внутренние узлы**: вопрос-предикат, обычно вида «признак xⱼ ≤ порог t»;
- **ветви**: исходы вопроса, в бинарном дереве две, «да» и «нет»;
- **листья**: итоговый ответ, класс или доля классов (вероятность), в регрессии среднее значение.

**Предсказание:** объект спускается от корня к листу, на каждом узле выбирая ветвь по ответу.
Ответ дерева это значение в листе.

**Пример из ЛР3.** Корень дерева: «спирт ≤ 10,25 %». Если да, дальше спрашивается летучая кислотность
≤ 0,265. Если нет, снова спирт ≤ 11,4. Так дерево выстраивает правила, которые можно прочитать как текст.

**Свойства:**
- интерпретируемость: решение объяснимо цепочкой правил;
- не нужно масштабировать признаки: сравнение с порогом не зависит от масштаба;
- умеет работать с нелинейными зависимостями и взаимодействиями признаков;
- граница между классами кусочно-постоянная, из отрезков, параллельных осям;
- склонность к переобучению: глубокое дерево запоминает выборку. В КР дерево без ограничений
  дало на тесте 0,946, но ROC-AUC тоже всего 0,946, потому что вероятности в листьях почти всегда 0 или 1;
- неустойчивость: небольшое изменение данных может полностью поменять дерево.

Последние два недостатка лечат ансамбли: случайный лес и бустинг.

## 13. Виды разделяющих функций

Разделяющая функция g(x) определяет, к какому классу отнести объект: по знаку g(x) в бинарной задаче
или по максимальному gₖ(x) в многоклассовой. Граница между классами это множество точек, где g(x) = 0.

**Линейная:** g(x) = wᵀx + b. Граница прямая на плоскости, гиперплоскость в многомерном пространстве.
Логистическая регрессия, линейный SVM, перцептрон. Просто и устойчиво, но только для линейно
разделимых классов.

**Кусочно-линейная:** граница из отрезков. Деревья решений делят пространство на прямоугольники
разбиениями, параллельными осям. Бывают и косые деревья, где в узле линейная комбинация признаков.

**Квадратичная:** g(x) = xᵀAx + wᵀx + b. Граница кривая второго порядка: эллипс, парабола, гипербола.
Получается, например, в квадратичном дискриминантном анализе, когда у классов разные ковариации.

**Нелинейная через ядра:** в SVM с ядром RBF g(x) = Σ αᵢyᵢK(xᵢ, x) + b, граница может быть сколь угодно
изогнутой. В ЛР3 такой SVM дал 0,769 против 0,732 у линейной модели.

**Метрическая:** kNN, граница определяется расстояниями до соседей, получается ломаная линия
(диаграмма Вороного).

**Нейросетевая:** многослойная сеть строит произвольную нелинейную границу как композицию простых функций.

**Выбор** зависит от данных: чем сложнее граница, тем больше данных нужно, чтобы не переобучиться.
В ЛР3 разрыв между линейной моделью и лесом (0,732 и 0,838) показывает, что граница качества вина
нелинейная.

## 14. Обучение дерева решений

Дерево строится жадно сверху вниз (алгоритмы ID3, C4.5, CART). В каждом узле перебираются все признаки
и все пороги, выбирается разбиение, которое сильнее всего уменьшает неоднородность классов в дочерних узлах.

**Меры неоднородности узла** с долями классов pₖ:
- индекс Джини: G = 1 − Σ pₖ². Ноль, когда в узле один класс; 0,5 для двух классов поровну;
- энтропия: H = −Σ pₖ·log₂ pₖ. Ноль при чистом узле, 1 при равных долях двух классов;
- для регрессии: дисперсия ответа в узле.

**Прирост информации:** из неоднородности родителя вычитается взвешенная неоднородность потомков:

  IG = H(родитель) − Σ (Nᵢ / N)·H(потомокᵢ)

Выбирается разбиение с максимальным приростом. В ЛР3 корень имел gini = 0,465 на 4872 объектах,
после разбиения по спирту узлы стали однороднее, справа gini = 0,312.

**Когда остановиться:**
- достигнута максимальная глубина (в ЛР3 max_depth = 8);
- в узле меньше минимального числа объектов (min_samples_leaf);
- разбиение не даёт прироста;
- узел однородный.

**Обрезка (pruning):** дерево строится глубоким, потом удаляются ветви, не улучшающие качество
на валидации.

**Жадность** означает, что каждое решение лучшее локально, а не для всего дерева. Найти оптимальное
дерево целиком вычислительно невозможно.

Без ограничений дерево переобучается: в каждом листе оказывается один объект, и точность на обучении 100 %.
Поэтому в КР и ЛР3 я ограничивал глубину и сравнивал одно дерево со случайным лесом.

## 15. Классификаторы

Классификатор это алгоритм, который по признакам объекта выдаёт его класс или вероятность класса.

**Основные классификаторы:**
- логистическая регрессия: линейная граница, вероятности через сигмоиду, быстро и интерпретируемо;
- k ближайших соседей: класс большинства среди k похожих объектов;
- дерево решений: правила «если, то», интерпретируемо, склонно к переобучению;
- случайный лес: сотни деревьев на случайных подвыборках, ответ голосованием;
- градиентный бустинг: деревья строятся по очереди, каждое исправляет ошибки предыдущих;
- метод опорных векторов: граница с максимальным зазором, с ядрами нелинейная;
- наивный байес: теорема Байеса при предположении независимости признаков;
- нейронные сети.

**Метрики качества:**
- accuracy: доля верных ответов, годится при сбалансированных классах;
- precision: из названных положительными какая доля правда положительная;
- recall: какую долю настоящих положительных нашли;
- F1: гармоническое среднее precision и recall, 2PR / (P + R);
- ROC-AUC: качество ранжирования, вероятность, что случайный положительный объект получит
  больший балл, чем случайный отрицательный; не зависит от порога;
- матрица ошибок: сколько объектов каждого класса куда отнесено.

**Сравнение в моих работах.** ЛР3, вино: лес 0,838, SVM 0,769, kNN 0,751, дерево 0,743,
логистическая регрессия 0,732. КР, авиапассажиры: бустинг 0,965, лес 0,962, дерево 0,946,
kNN со стандартизацией 0,928, логистическая регрессия 0,875.

Общий вывод: на табличных данных с нелинейными зависимостями ансамбли деревьев обычно лучшие,
но выбирать классификатор надо сравнением на кросс-валидации, а не по привычке.

## 16. Кластеризация

Кластеризация это разбиение объектов на группы (кластеры) так, чтобы внутри группы объекты были
похожи, а между группами различались. Меток нет, это обучение без учителя.

**Что нужно определить:**
- меру сходства: евклидово расстояние, манхэттенское, косинусная близость для текстов;
- число кластеров, если метод его требует;
- способ масштабирования: без стандартизации признак с большими значениями задавит остальные.
  В КР перед K-Means я стандартизировал признаки, иначе дальность полёта в тысячи километров
  определяла бы всё.

**Основные методы:**
- K-Means: центры кластеров и приписывание объектов к ближайшему центру;
- иерархическая кластеризация: дерево вложенных кластеров;
- DBSCAN: кластеры как области высокой плотности, находит кластеры любой формы и выбросы;
- смеси гауссовых распределений: мягкое отнесение к кластерам с вероятностями.

**Оценка качества:**
- внутренние меры (без меток): инерция (сумма квадратов расстояний до центров), силуэт;
- внешние меры (если есть настоящие метки для проверки): скорректированный индекс Рэнда ARI.

**Пример из КР.** Я проверил, делятся ли авиапассажиры на естественные группы. Метод локтя не показал
излома: инерция падала плавно от 2,86 млн при k = 1 до 1,79 млн при k = 8. Кластеры K-Means при k = 2
совпали с настоящими классами удовлетворённости слабо, ARI = 0,28. Вывод: для этой задачи нужна
модель с учителем.

Применения: сегментация клиентов, группировка документов, сжатие изображений, предобработка данных.

## 17. Обучение без учителя

Обучение без учителя работает с данными без правильных ответов. Модель ищет структуру в самих данных:
группы, закономерности, скрытые факторы, необычные объекты.

**Основные задачи:**
- **кластеризация**: группировка похожих объектов (K-Means, иерархическая, DBSCAN);
- **понижение размерности**: сжатие признаков с сохранением информации. PCA поворачивает оси
  в направления максимальной дисперсии. В КР две главные компоненты из 22 признаков объяснили 29,4 %
  дисперсии, в ПР5 для векторов рецензий 23,7 %;
- **обнаружение аномалий**: поиск объектов, не похожих на остальные. В ПР3 автокодировщик учился
  только на нормальных данных, и всё, что он плохо восстанавливал, считалось аномалией.
  На двумерном примере он нашёл все 7 аномалий из 7, а на реальном наборе WBC с порогом
  по 99-му процентилю только 38 % злокачественных опухолей при 1,4 % ложных тревог;
- **оценка плотности**: восстановление распределения данных;
- **обучение представлений**: векторы слов (word2vec, Navec в ПР5) обучены без разметки, только
  по соседству слов в текстах.

**Сложности:**
- нет однозначной метрики качества, потому что нет правильных ответов;
- результат зависит от масштаба признаков, меры расстояния, числа кластеров;
- найденная структура может не совпадать с тем, что интересно человеку.

**Зачем нужно:** разметка дорогая, а неразмеченных данных много. Обучение без учителя помогает понять
данные до построения модели, сжать признаки, найти выбросы и заготовить представления для задач
с учителем.

## 18. Обучение с учителем

В обучении с учителем есть выборка пар (xᵢ, yᵢ): объект и правильный ответ. Модель учится по объекту
предсказывать ответ и должна работать на новых объектах.

**Постановка:** найти функцию a(x) из семейства моделей, минимизирующую функцию потерь на обучающих
данных: Σ L(yᵢ, a(xᵢ)). Для регрессии обычно MSE, для классификации log-loss.

**Две основные задачи:** классификация (конечный набор классов) и регрессия (число).

**Главная проблема: обобщение.**
- недообучение: модель слишком простая, плохо и на обучении, и на тесте;
- переобучение: модель запомнила обучающие данные, на обучении отлично, на тесте плохо.
  В ЛР4 своя сеть: на обучении 0,583, на валидации 0,46, разрыв растёт с 25-й эпохи.

**Как проверяют качество:**
- выборку делят на обучающую, валидационную и тестовую. На валидации подбирают параметры,
  тест трогают один раз в конце. В ЛР1 я отложил ещё тысячу изображений для верификации: 0,887
  против 0,888 на тесте;
- кросс-валидация: выборка делится на k частей, модель k раз учится на k − 1 частях и проверяется
  на оставшейся;
- для временных рядов разбиение только по времени (ПР2), иначе модель увидит будущее.

**Приёмы против переобучения:** регуляризация, ограничение сложности, дропаут, ранняя остановка,
аугментация, больше данных.

Все мои лабораторные с классификацией и регрессией это обучение с учителем: КР, ЛР1–ЛР4, ПР2, ПР5.

## 19. Смешанный алгоритм обучения

Смешанное (гибридное) обучение сочетает этапы без учителя и с учителем в одной модели.

**Классический пример: сеть радиально-базисных функций (RBF).** Обучается в два этапа:
1. Без учителя: центры скрытых нейронов находятся кластеризацией (например, K-Means) по входным данным.
   Каждый нейрон отвечает на близость к своему центру: φⱼ(x) = exp(−‖x − μⱼ‖² / 2σ²).
2. С учителем: веса выходного слоя подбираются по правильным ответам, это обычная линейная регрессия
   поверх выходов скрытого слоя.

Так обучение идёт быстрее, чем обратное распространение по всей сети.

**Близкое понятие: частичное обучение (semi-supervised).** Размеченных данных мало, неразмеченных много.
Подходы:
- самообучение: модель обучается на размеченных, размечает неразмеченные с высокой уверенностью
  (псевдометки) и дообучается;
- распространение меток: метки передаются похожим объектам по графу близости;
- совместное обучение: две модели на разных наборах признаков размечают данные друг для друга.

**Современный вариант: предобучение и дообучение.** Модель сначала учится на большом объёме данных
без разметки или на другой задаче, потом дообучается на своей небольшой размеченной выборке.
В ЛР4 свёрточные слои ResNet18 уже умели выделять признаки изображений, я обучил только последний слой
на 1750 фотографиях и получил 0,664 против 0,501 у сети с нуля. В ПР5 векторы слов Navec обучены
без учителя на художественных текстах, а поверх них логистическая регрессия обучена с учителем
на рецензиях: 0,891.

Смысл во всех случаях один: без учителя модель извлекает структуру данных, с учителем настраивается
на конкретную задачу.

## 20. Алгоритм k-средних (k-means)

K-means разбивает n объектов на k кластеров, где каждый кластер задаётся центром (центроидом).

**Целевая функция:** минимизировать сумму квадратов расстояний объектов до центров своих кластеров,
её называют инерцией:

  J = Σₖ Σ_{x ∈ Cₖ} ‖x − μₖ‖²

**Алгоритм:**
1. Выбрать k начальных центров.
2. Отнести каждый объект к ближайшему центру.
3. Пересчитать каждый центр как среднее своих объектов.
4. Повторять шаги 2 и 3, пока отнесение не перестанет меняться.

Каждый шаг не увеличивает J, поэтому алгоритм сходится, но к локальному минимуму.

**Инициализация k-means++:** первый центр случайный, каждый следующий выбирается с вероятностью,
пропорциональной квадрату расстояния до ближайшего уже выбранного. Центры получаются разнесёнными.
Плюс алгоритм запускают несколько раз и берут лучший результат (в КР n_init = 10).

**Выбор k:**
- метод локтя: график инерции от k, ищется излом, после которого снижение замедляется;
- силуэт: насколько объект ближе к своему кластеру, чем к соседнему;
- смысл задачи.

**Ограничения:**
- число кластеров задаётся заранее;
- находит только выпуклые кластеры примерно одного размера;
- чувствителен к масштабу признаков и к выбросам.

**Пример из КР:** на стандартизированных данных авиапассажиров инерция падала плавно, с 2 857 360
при k = 1 до 1 794 612 при k = 8, излома не было. Кластеры при k = 2 совпали с настоящими классами
удовлетворённости слабо, ARI = 0,28.

## 21. Иерархическая кластеризация

Иерархическая кластеризация строит не одно разбиение, а дерево вложенных кластеров, дендрограмму.

**Два подхода:**
- **агломеративный (снизу вверх):** сначала каждый объект сам по себе кластер, на каждом шаге
  сливаются два ближайших кластера, пока не останется один;
- **дивизивный (сверху вниз):** все объекты в одном кластере, который последовательно делится.
  Используется реже, дороже.

**Расстояние между кластерами (способ связи):**
- одиночная связь: расстояние между ближайшими объектами двух кластеров. Находит вытянутые кластеры,
  но склонна к «цепочкам»;
- полная связь: между самыми далёкими объектами, даёт компактные кластеры;
- средняя связь: среднее по всем парам объектов;
- метод Уорда: сливаются кластеры, при объединении которых меньше всего растёт внутрикластерная
  дисперсия. Результат похож на k-means.

**Дендрограмма:** по горизонтали объекты, по вертикали расстояние, на котором кластеры слились.
Число кластеров выбирается разрезом дендрограммы на нужной высоте: большой скачок высоты между
слияниями подсказывает естественное число кластеров.

**Достоинства:**
- не нужно задавать число кластеров заранее;
- дендрограмма наглядно показывает структуру данных на всех уровнях;
- результат детерминированный, без случайной инициализации.

**Недостатки:**
- вычислительная сложность: нужна матрица попарных расстояний, память O(n²), время от O(n²);
  на 130 тысячах объектов из КР это неподъёмно, поэтому там я использовал k-means;
- слияние необратимо: ошибка на раннем шаге сохраняется до конца;
- чувствительность к выбросам и масштабу.

## 22. Метод опорных векторов

Метод опорных векторов (SVM) строит разделяющую гиперплоскость с максимальным зазором между классами.

**Линейный случай:** граница wᵀx + b = 0, классы yᵢ ∈ {−1, +1}. Требуется, чтобы все объекты лежали
не ближе определённого расстояния от границы: yᵢ(wᵀxᵢ + b) ≥ 1. Ширина зазора равна 2 / ‖w‖,
значит максимизация зазора сводится к минимизации ‖w‖²:

  min ½‖w‖²  при  yᵢ(wᵀxᵢ + b) ≥ 1

**Опорные векторы:** объекты, лежащие точно на краю зазора. Только они определяют положение границы,
остальные объекты можно убрать, и решение не изменится.

**Мягкий зазор:** реальные данные не разделяются идеально, поэтому разрешаются нарушения ξᵢ:

  min ½‖w‖² + C·Σ ξᵢ  при  yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ

Параметр C регулирует компромисс: большое C строго штрафует ошибки (риск переобучения), маленькое
допускает ошибки ради широкого зазора.

**Ядра:** для нелинейных границ скалярное произведение заменяется функцией ядра K(x, x′).
Это то же, что перейти в пространство большей размерности, но без явного вычисления признаков:
- полиномиальное ядро: (xᵀx′ + c)ᵈ;
- гауссово RBF: exp(−γ‖x − x′‖²).

**Свойства:** хорошо работает в высокой размерности и на небольших выборках, требует масштабирования
признаков, медленно на больших данных (обучение от O(n²)), вероятности даёт только через калибровку.

**Пример из ЛР3:** SVM с ядром RBF на стандартизированных признаках вина дал accuracy 0,7686 и ROC-AUC
0,829, второе место после случайного леса, но обучался дольше всех: 1,55 с против 0,39 с у леса.

## 23. Метод k ближайших соседей

kNN относит объект к классу, который преобладает среди k ближайших к нему объектов обучающей выборки.
Для регрессии ответ это среднее ответов соседей.

**Алгоритм:**
1. Посчитать расстояние от нового объекта до всех объектов обучающей выборки.
2. Выбрать k ближайших.
3. Ответить классом большинства (или взвешенным голосованием, где ближние соседи весят больше).

**Обучения как такового нет:** модель просто запоминает выборку, вся работа при предсказании.
Поэтому kNN называют ленивым алгоритмом.

**Мера расстояния:** евклидова √Σ(xᵢ − x′ᵢ)², манхэттенская Σ|xᵢ − x′ᵢ|, косинусная для текстов.

**Выбор k:** маленькое k даёт шумную границу и переобучение, большое сглаживает и может смазать
мелкие классы. Подбирается кросс-валидацией. В ЛР3 я взял k = 15, в КР k = 5.

**Масштабирование обязательно.** Это самый наглядный результат моих работ. В КР kNN без
стандартизации дал accuracy 0,7528: расстояние определял признак дальности полёта со значениями
до 4983, а оценки сервиса от 0 до 5 почти не влияли. После стандартизации 0,9283, прирост
17,6 процентного пункта, больше, чем от любого другого улучшения.

**Проклятие размерности:** в пространстве с большим числом признаков все объекты оказываются
примерно на одинаковом расстоянии, и понятие «ближайший» теряет смысл.

**Достоинства:** простота, отсутствие предположений о форме границы, легко добавить новые данные.
**Недостатки:** медленное предсказание на больших выборках, чувствительность к масштабу
и неинформативным признакам, большой расход памяти.

## 24. Логистическая регрессия

Логистическая регрессия это линейный классификатор, который выдаёт вероятность класса.

**Модель:**

  P(y = 1 | x) = σ(wᵀx + b) = 1 / (1 + e^−(wᵀx + b))

Решение: класс 1, если вероятность больше порога, обычно 0,5. Это то же, что wᵀx + b > 0, поэтому
граница линейная.

**Интерпретация коэффициентов.** Логарифм шансов линеен по признакам:

  ln(p / (1 − p)) = wᵀx + b

Рост признака xⱼ на единицу умножает шансы класса 1 в e^(wⱼ) раз. Знак веса показывает направление
влияния.

**Обучение:** минимизация log-loss (см. вопрос 5) градиентным спуском или методами второго порядка,
аналитического решения нет. Регуляризация L2 или L1 добавляется к функции потерь.

**Многоклассовый случай:** либо «один против всех», либо softmax: P(y = k | x) = e^(wₖᵀx) / Σⱼ e^(wⱼᵀx).
Выходной слой нейросети с softmax это многоклассовая логистическая регрессия.

**Пример из ЛР2.** На мешке слов модель сама нашла оценочную лексику: самые отрицательные веса
у worst (−2,2), waste (−1,9), awful (−1,4), самые положительные у excellent, amazing, wonderful
(около +1,3). На TF-IDF accuracy 0,8736, и она обогнала рекуррентную сеть LSTM на 13 процентных пунктов.

**Достоинства:** быстро обучается, вероятности на выходе, веса можно читать.
**Недостатки:** только линейная граница, чувствительна к масштабу признаков при оптимизации:
в КР без стандартизации не сошлась за 1000 итераций.

## 25. Бинарная линейная классификация

Задача: разделить объекты на два класса y ∈ {−1, +1} линейной функцией:

  a(x) = sign(wᵀx + b)

Граница wᵀx + b = 0 это гиперплоскость, w перпендикулярен ей, b сдвигает её от начала координат.

**Отступ (margin)** объекта: Mᵢ = yᵢ(wᵀxᵢ + b). Если Mᵢ > 0, объект классифицирован верно, и чем больше
отступ, тем увереннее. Если Mᵢ < 0, ошибка.

**Функция потерь.** Естественная потеря это число ошибок, [Mᵢ < 0]. Но она разрывная, и оптимизировать
её градиентом нельзя. Поэтому её заменяют гладкими верхними оценками, и от выбора оценки зависит метод:
- логистическая: ln(1 + e^(−M)) даёт логистическую регрессию;
- кусочно-линейная (hinge): max(0, 1 − M) даёт метод опорных векторов;
- перцептронная: max(0, −M) даёт перцептрон;
- экспоненциальная: e^(−M) используется в AdaBoost.

Все они штрафуют маленькие и отрицательные отступы, отличаются тем, насколько сильно наказывают
уверенные ошибки и нужен ли запас для верных ответов.

**Обучение:** минимизация суммарной потери с регуляризацией, Σ L(Mᵢ) + λ‖w‖², градиентным спуском.

**Ограничение:** работает, только если классы примерно линейно разделимы. Иначе помогают базисные
функции, ядра или переход к нелинейным моделям.

**Пример:** в ЛР3 линейная модель дала 0,732 против 0,838 у случайного леса, то есть граница
качества вина явно нелинейная. В ЛР2, наоборот, линейная модель на 20 000 признаков TF-IDF дала 0,874:
в высокоразмерном пространстве слов классы разделяются гиперплоскостью хорошо.

## 26. Задача кластеризации

**Постановка.** Дано множество объектов X = {x₁, …, xₙ} и функция расстояния ρ(x, x′). Требуется
разбить X на непересекающиеся подмножества, кластеры, так, чтобы объекты внутри одного кластера
были близки, а объекты разных кластеров далеки. Каждому объекту приписывается метка кластера aᵢ.

Формально, например, минимизировать среднее внутрикластерное расстояние

  F₀ = Σ [aᵢ = aⱼ]·ρ(xᵢ, xⱼ) / Σ [aᵢ = aⱼ]

и одновременно максимизировать межкластерное.

**Некорректность задачи.** В отличие от классификации, у кластеризации нет единственного правильного
ответа:
- неизвестно число кластеров;
- результат зависит от выбранной меры расстояния и масштаба признаков;
- разные методы на одних данных дают разные разбиения, и все они могут быть осмысленными.

**Цели кластеризации:**
- понять структуру данных, выделить типичные группы (сегментация клиентов);
- сжать данные, заменив объекты центрами кластеров;
- найти нетипичные объекты, не попавшие ни в один кластер.

**Оценка качества:**
- внутренняя: инерция, силуэт, индекс Дэвиса-Болдина. Не требует меток;
- внешняя: если для проверки есть настоящие классы, считается согласие с ними,
  например скорректированный индекс Рэнда (1 полное совпадение, 0 случайное).

**Методы** (подробнее в вопросах 16, 20, 21): k-means, иерархическая, DBSCAN, смеси распределений.

**Пример из КР.** Задача: есть ли среди авиапассажиров естественные группы. Метод локтя излома не дал,
ARI кластеров с классами удовлетворённости 0,28. Вывод: кластеры есть, но они отражают тип поездки
и класс обслуживания, а не удовлетворённость. Кластеризация помогла понять данные, но предсказывать
удовлетворённость пришлось с учителем.
