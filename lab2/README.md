# ЛР2: анализ тональности текста (IMDB)

«Методы машинного обучения», Московский Политех, группа 231-329, Арутюнян Ф. Р.
Вариант 1: выборка 10 000 отзывов.

Два подхода к определению тональности: мешок слов и TF-IDF с логистической регрессией
против рекуррентной сети LSTM.

Лучший результат: TF-IDF + логрегрессия, accuracy 0,8736, ROC-AUC 0,9437.
LSTM 0,7396. Обязательная таблица по числу отзывов в разделе 7 ноутбука.

## Данные

`data/imdb_dataset.csv` — файл `IMDB_dataset.xlsx` из материалов к работе, переведённый в csv:
25 000 отзывов, поровну положительных и отрицательных.

## Запуск

```bash
../.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebook.ipynb
```

Полный прогон около пяти минут, из них четыре на обучение LSTM.
