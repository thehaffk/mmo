# ЛР3: применение классификаторов (Wine Quality)

«Методы машинного обучения», Московский Политех, группа 231-329, Арутюнян Ф. Р.

Пять классификаторов на табличных данных: логистическая регрессия, k ближайших соседей,
дерево решений, случайный лес и метод опорных векторов.

Лучший результат: случайный лес, accuracy 0,8382, F1 0,8760, ROC-AUC 0,8968.

## Данные

Wine Quality из UCI, 6497 вин. Файлы скачиваются в `data/` при первом запуске ноутбука.

## Запуск

```bash
../.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebook.ipynb
```

Прогон около минуты.

## Файлы

- `notebook.ipynb` весь разбор, 9 графиков
- `figures/` графики в png
- `report.md` → `report.docx` (`node ../tools/gost_report.js report.md report.docx`)
- `defense.md` шпаргалка к защите
