# ЛР5: создание датасета из журнала активности и его анализ

«Методы машинного обучения», Московский Политех, группа 231-329, Арутюнян Ф. Р.

По мотивам примера `Анализ-активности` из материалов к работе: журнал активности
собирается из экспорта чата Telegram, приводится к таблице и анализируется.

Результат: `data/messages.csv`, 26 521 сообщение, 14 столбцов, без текстов и настоящих имён.

## Данные

Исходный экспорт `data/result.json` в репозиторий не выгружается. Чтобы пересобрать датасет,
положите свой экспорт чата (Telegram Desktop → Экспорт истории чата → JSON) в `data/result.json`.

## Запуск

```bash
../.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebook.ipynb
```

## Файлы

- `notebook.ipynb` сборка, анализ, 6 графиков
- `data/messages.csv` итоговый датасет
- `report.md` → `report.docx` (`node ../tools/gost_report.js report.md report.docx`)
- `defense.md` шпаргалка к защите
