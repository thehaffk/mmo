# ПР2: знакомство с рекуррентной нейронной сетью

«Методы машинного обучения», Московский Политех, группа 231-329, Арутюнян Ф. Р.

Прогноз суточной минимальной температуры в Мельбурне по окну из 30 дней.
Сравнение LSTM с наивным прогнозом и линейной регрессией.

Результат: LSTM MAE 1,735 °C и R² 0,675, линейная регрессия 1,745 и 0,670,
наивный прогноз 2,036 и 0,565.

## Данные

Ряд Daily Minimum Temperatures (3650 значений) скачивается в `data/` при первом запуске.

## Запуск

```bash
../.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebook.ipynb
```

Прогон около минуты.
