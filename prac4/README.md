# ПР4: датасет из открытого API GitHub

«Методы машинного обучения», Московский Политех, группа 231-329, Арутюнян Ф. Р.
Парная к ЛР5, другой источник данных.

Через API поиска GitHub (без авторизации) собраны репозитории, созданные 1–15 августа 2025 года:
по 100 популярных и 100 обычных за день. Результат: `data/github_repos.csv`, 2978 репозиториев,
15 столбцов, без имён. Модель отличает популярный репозиторий от обычного с ROC-AUC 0,80.

## Запуск

```bash
../.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebook.ipynb
```

Сырой ответ лежит в `data/raw_github_repos.json`, ноутбук берёт его и в сеть не ходит.
Чтобы собрать заново, удалите файл: сбор займёт около 3,5 минуты из-за лимита 10 запросов в минуту.

## Файлы

- `notebook.ipynb` сбор, разбор, анализ, модель, 4 графика
- `data/raw_github_repos.json` сырой ответ API
- `data/github_repos.csv` итоговый датасет
- `report.md` → `report.docx` (`node ../tools/gost_report.js report.md report.docx`)
- `defense.md` шпаргалка к защите
