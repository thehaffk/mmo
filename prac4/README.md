# ПР4: датасет из истории коммитов git

«Методы машинного обучения», Московский Политех, группа 231-329, Арутюнян Ф. Р.
Парная к ЛР5, другой источник данных.

Результат: `data/commits.csv`, 1949 коммитов из шести репозиториев, 15 столбцов,
имена авторов заменены псевдонимами.

## Запуск

Ноутбук читает локальные репозитории по путям из словаря `REPOS`. Чтобы пересобрать датасет
на своей машине, поправьте пути.

```bash
../.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebook.ipynb
```

## Файлы

- `notebook.ipynb` сбор, разбор, анализ, 5 графиков
- `data/commits.csv` итоговый датасет
- `report.md` → `report.docx` (`node ../tools/gost_report.js report.md report.docx`)
- `defense.md` шпаргалка к защите
